# Streamline Carports: Single Carport Mockup

An interactive CRO (Conversion Rate Optimisation) prototype for the Streamline Carports single carport configurator page.

Repository: https://github.com/Lilmonstersam/streamline-carport-single-mockup.git

## Features

- **Interactive Configurator**: Multi-step layout allowing users to choose dimensions (Length x Width) and custom colours (for roof, posts, and trim).
- **Tabbed Spec Widget**: Clean tabbed interface showing descriptions, key features, delivery options, specifications, and assembly instructions.
- **Enquiry Flow**: Pop-up form that automatically carries over the configured carport options to the final enquiry.
- **NZ-Specific Copy**: Designed specifically for the New Zealand market (using local contact numbers, factory pickup in Palmerston North, and NZ-wide freight).

## Local Usage

This is a static HTML mockup with no build steps or external dependencies. To run it locally:

1. Clone this repository.
2. Open `index.html` directly in any web browser.

## GitHub Pages Deployment

This repository is configured to deploy directly to GitHub Pages.

### Set up Steps

1. Push this project to the `main` branch of `Lilmonstersam/streamline-carport-single-mockup`.
2. In GitHub, go to **Settings > Pages**.
3. Under **Build and deployment > Source**, select **Deploy from a branch**.
4. Set the branch to `main` and folder to `/` (root), then click **Save**.
5. The mockup will be live at: `https://lilmonstersam.github.io/streamline-carport-single-mockup/`
